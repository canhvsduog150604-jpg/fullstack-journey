    Cách mình hướng dẫn bạn

    Mọi bài nằm trong thư mục C:\Users\ADMIN\fullstack-journey, mỗi trạm một thư mục con.

    1. Nhận bài

    Nói “bài tiếp theo”. Mình tạo file bài học: lý thuyết ngắn, ví dụ, bài tập và file khởi đầu.

    2. Tự code

    Tự làm trước. Bí quá 30 phút thì hỏi mình gợi ý, mình sẽ không đưa ngay đáp án.

    3. Chấm bài

    Nói “chấm bài”. Mình đọc code, chạy thử, chỉ ra lỗi và cách viết gọn hơn.

    4. Commit

    Bài đạt thì git commit và push, tick ô trên trang này, sang bài kế.

    Tiến độ chỉ lưu trên trình duyệt này.
