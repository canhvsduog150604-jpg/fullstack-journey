# fullstack-journey

Hành trình học Full-stack trong 16 tuần: HTML/CSS/JS → HTTP → Python → SQL → FastAPI → Deploy → Docker, kèm DSA song song.

| Thư mục | Trạm |
|---|---|
| `00-setup` | Môi trường và Git |
| `01-html-css-js` | HTML, CSS, JavaScript |
| `02-http-fetch` | HTTP và fetch() |
| `03-python` | Python và OOP |
| `04-sql` | SQL và database |
| `05-fastapi` | FastAPI, CRUD, JWT |
| `06-fullstack` | Nối frontend và backend |
| `07-deploy` | Deploy |
| `08-docker` | Docker |
| `dsa` | Cấu trúc dữ liệu và giải thuật |

Mở `roadmap.html` để xem lộ trình.
